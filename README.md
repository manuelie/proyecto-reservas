# Sistema de Reservas

Proyecto desarrollado en Java con interfaz gráfica para la gestión de reservas.

## Descripción

Esta aplicación permite gestionar reservas mediante una interfaz gráfica sencilla e intuitiva. El sistema facilita el registro, consulta y administración de datos relacionados con las reservas.

## Funcionalidades

- Registro de reservas.
- Consulta de reservas existentes.
- Validación de datos introducidos por el usuario.
- Interfaz gráfica amigable.
- Gestión de información almacenada.

## Tecnologías utilizadas

- Java
- Swing (Interfaz gráfica)
- NetBeans

## Instalación y ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en NetBeans.
3. Compilar y ejecutar la aplicación.
